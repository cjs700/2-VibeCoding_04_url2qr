## 1. 프로젝트 개요

- **프로젝트명**: URL2QR (스마트 인터랙티브 QR 코드 웹 생성기)
- **목적**: 간편하고 직관적인 URL 입력으로 고품질 QR 코드를 즉시 생성하고, 제공해주신 **노란색 `URL2QR` 로고**와 완벽하게 조화되는 웜 골드/앰버 톤의 감각적인 모던 디자인 및 마우스 반응형 그라데이션 인터랙션을 제공하는 웹 애플리케이션.
- **핵심 특징**:
  - 화면 상단 좌측에 `img/` 폴더 내의 **URL2QR 로고(`logo.png` / `이미지.png`)** 배치 및 클릭 시 상태 리셋
  - 첫 진입 시 정중앙 심플 URL 입력창 배치
  - URL 입력 및 확인 시 URL 입력창이 하단으로 부드럽게 이동하고, 화면 정중앙에 QR 코드 생성
  - 생성된 QR 코드 클릭 시 고화질 **JPG 이미지(`qrcode.jpg`)** 다운로드
  - `URL2QR` 로고와 완벽하게 어우러지는 웜 앰버/골든 옐로우 톤 & 글래스모피즘(Glassmorphism) UI
  - 마우스 커서 위치(`mousemove`) 및 모바일 터치(`touchmove`)에 실시간 반응하는 오로라 그라데이션

## 2. 구현 계획 (Implementation Plan)

### 📌 1단계: 기본 기능 및 레이아웃 구현 (프롬프트 1)
1. **로고 영역 구성**:
   - `img/` 폴더 내 제공된 실제 로고 이미지(`img/logo.png`, `img/이미지.png`)를 화면 상단 좌측에 배치.
2. **중앙 입력창 인터페이스**:
   - 화면 정중앙에 심플하고 명확한 URL 입력 폼과 확인 버튼 제작.
3. **상태 전환 애니메이션 (Layout Transition)**:
   - 입력 확인 시 `.has-qr` 클래스를 활성화하여 URL 입력창은 하단으로 부드럽게 이동, 정중앙에 QR 코드가 스케일업/페이드인.
4. **QR 코드 생성 및 JPG 다운로드**:
   - `qrcode.js` 라이브러리를 통해 입력된 URL로 고정밀 QR 코드 생성.
   - 캔버스 변환 및 여백(Padding)을 적용한 `image/jpeg` 포맷 다운로드 트리거.

### 📌 2단계: 디자인 고도화 및 인터랙티브 효과 (프롬프트 1-2)
1. **로고 맞춤형 밝은 톤(Bright Theme) 전환**:
   - 제공된 `URL2QR` 로고의 메인 색상인 골든 옐로우(#f59e0b, #fbbf24) 및 앰버(#d97706)와 조화를 이루는 따뜻한 크림/화이트 배경 및 다크 차콜(#1c1917) 폰트 적용.
   - 글래스모피즘 카드 디자인(블러 20px, 화사한 소프트 보더, 입체 그림자).
2. **마우스 반응형 인터랙티브 그라데이션**:
   - 마우스 커서의 X, Y 좌표를 실시간 추적하여 CSS 변수(`--mouse-x`, `--mouse-y`, `--grad-hue1~3`)에 선형 보간(Lerp)으로 부드럽게 적용.
   - 마우스 커서의 위치에 따라 골드, 앰버, 코랄 톤의 색조(Hue)가 유기적으로 변화.

## 3. 워크스루 (Walkthrough & User Flow)

```
[1. 첫 화면 접속] 
   │  - 화면 좌측 상단: 실제 URL2QR 노란색 로고 (img/logo.png)
   │  - 화면 정중앙: 심플하고 세련된 URL 입력창
   │  - 배경: 마우스 커서를 따라 부드럽게 빛과 앰버/골드 색조가 변화하는 오로라 그라데이션
   ▼
[2. URL 입력 및 확인]
   │  - 웹 주소 입력 (예: https://naver.com 또는 naver.com)
   │  - '확인' 버튼 클릭 또는 엔터(Enter) 입력
   ▼
[3. 인터랙티브 레이아웃 전환]
   │  - URL 입력창이 아래쪽으로 부드럽게 이동
   │  - 화면 정중앙에 선명한 QR 코드 카드가 팝업/페이드인
   ▼
[4. QR 코드 클릭 및 다운로드]
   │  - QR 코드 카드에 마우스 호버 시 "JPG 다운로드" 안내 표시
   │  - 클릭 시 즉시 흰색 여백이 포함된 깔끔한 'qrcode.jpg' 파일 저장
   ▼
[5. 초기화 / 재입력]
   │  - 좌측 상단 로고 클릭 시 첫 화면 상태로 리셋
   │  - 또는 하단 입력창에서 새로운 URL 입력 시 즉시 새 QR 코드 갱신
```

## 5. 기술 스택 및 파일 구조

### 🛠️ 기술 스택
- **HTML5**: 시맨틱 웹 표준 구조
- **Vanilla CSS3**: CSS 변수(Custom Properties), Glassmorphism, CSS Transitions & Keyframes
- **Vanilla JavaScript (ES6+)**: `requestAnimationFrame`, 이벤트 리스너, Canvas API, File Download Trigger
- **QRCode.js**: 클라이언트 사이드 QR 코드 벡터/캔버스 렌더링 라이브러리
